usage: orbit [-h] [--version]
             {doctor,inspect,analyze,run,render,separate,project,serve} ...

ORBIT local spatial audio CLI / HTTP API. No desktop control.

positional arguments:
  {doctor,inspect,analyze,run,render,separate,project,serve}
    doctor              Check local engine dependencies (no model downloads)
    inspect             Decode audio and report duration / waveform
    analyze             Measured source/clip/node STFT and spectrum for an
                        object in a saved project
    run                 Execute one JSON request, using the same schema as the
                        API
    render              Render a saved project to headphone binaural stereo
    separate            Demucs separation into a NEW output directory
    project             Portable .orbit projects, objects and animation
    serve               Start token-authenticated HTTP API on 127.0.0.1 only

options:
  -h, --help            show this help message and exit
  --version             show program's version number and exit
