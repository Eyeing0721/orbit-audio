GOOD TO KNOW

开始之前，
说清楚几件事。

这是 Dolby Atmos 吗？+

不是。ORBIT 输出的是基于 HRTF 的双声道双耳空间音频，适合用耳机聆听。不支持 Dolby Atmos ADM/JOC 导出，也没有杜比认证。个体听感会因耳机和 HRTF 匹配程度有所不同。

可以边拖动对象边实时听吗？+

初版采用离线试听与离线渲染。试听会先计算一段最长 20 秒的音频再播放，不是实时低延迟 DAW。频谱也需要手动计算，并非实时总线分析。

软件免费吗？音乐会上传吗？+

ORBIT 应用代码以 MIT 许可证开源，不依赖收费 DAW，音频制作在本地运行，不会因为使用本官网就上传你的音频。第三方组件、HRTF 数据与模型遵循各自授权；官网不提供上传音频的服务。

为什么下载后还要配置环境？+

便携包包含编辑器与引擎代码，不包含 Python 运行环境、FFmpeg 或 Demucs 模型权重。请按配置指南安装。已验证开发环境为 Windows 11 x64，其他系统与硬件组合尚未完成完整验证。

预览版有哪些需要留意的地方？+

原生 Windows 交互尚未完成完整稳定性验证，不能把自动化测试通过视为全部问题已修复。节点参数为静态设置，变速也会改变音高；峰值保护不等于真峰值限制或 LUFS 标准化。请保留原始素材与工程备份。
